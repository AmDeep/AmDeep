## About

I'm an **ML/AI engineer** based in Toronto building practical systems that move from model output to useful, inspectable action — across applied AI, retrieval-augmented generation, physical AI / robotics, and edge deployment.

> I care about the full path: data contracts → inference → agent workflows → interfaces → deployment → observability and safety boundaries.

**Focus areas**
- Physical AI & robotics (ROS 2 contracts, safety gateways, navigation bridges, fleet telemetry)
- Reliable agent systems and grounded copilots
- Production-minded serving, evaluation, and edge vision
- End-to-end product engineering (Python services, React/TypeScript, APIs, cloud)

<img src="profile/loop.svg" alt="Engineering loop: data → models → product → validation → edge, with evaluation feedback" width="100%">

<details>
<summary><b>How I approach engineering</b></summary>

- **Make behavior inspectable.** Keep inputs, outputs, assumptions, and evaluation visible.
- **Constrain before connecting.** Validate generated plans and commands at deterministic system boundaries.
- **Design for the whole path.** Treat data, inference, application interfaces, deployment, and observability as one system.
- **Prefer evidence over claims.** Prefer runnable labs, benchmarks, and typed contracts over slide-ware.

</details>
