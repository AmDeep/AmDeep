## About

I'm an **ML/AI engineer** based in Toronto who builds systems that move from model output to **useful, inspectable action**.

I work across the full path: data contracts → inference → agent workflows → product interfaces → deployment → observability and safety boundaries.

**Focus areas**
- **Physical AI & robotics** — ROS 2 contracts, safety gateways, navigation bridges, fleet telemetry
- **Reliable agent systems** — grounded copilots, constrained planners, evaluation loops
- **Production ML** — serving, edge vision, typed schemas, fallback strategies
- **Product engineering** — Python services, React/TypeScript, APIs, cloud workflows

<img src="https://raw.githubusercontent.com/AmDeep/AmDeep/main/profile/loop.svg" alt="Engineering loop from data through models, product, validation and edge systems" width="100%" />

<details>
<summary><b>Engineering principles</b></summary>

- **Make behavior inspectable.** Keep inputs, outputs, assumptions, and evaluation visible.
- **Constrain before connecting.** Validate generated plans and commands at deterministic system boundaries.
- **Design for the whole path.** Treat data, inference, application interfaces, deployment, and observability as one system.
- **Prefer evidence.** Runnable labs, benchmarks, and typed contracts over slide-ware.

</details>
